   - Return dict: `{"city": city_name, "current": {...}, "forecast": [...up to `days` items]}`

   - Use `tenacity` retry decorator (same pattern as existing methods)
   - Log API call count increment
   - Fallback: if city not in CityConfig (no adcode), return error "暂不支持该城市的天气查询"

```python
"""POI search tool — searches curated DB data and Amap API (BIZ-01)."""

import json
from agents import function_tool, RunContextWrapper
from backend.agent.context import AgentContext

@function_tool
async def search_pois(
    ctx: RunContextWrapper[AgentContext],
    city: str,
    keyword: str = "",
) -> str:
    """搜索城市中的兴趣点（餐厅、景点、咖啡馆等）。
    
    Args:
        city: 城市名称，如"上海"、"杭州"
        keyword: 搜索关键词，如"咖啡馆"、"日料"、"博物馆"，可为空
    """
```
 Implementation:
- Get `db_session` and `amap_service` from `ctx.context`
- First query DB: `select(POI).where(POI.city == city)` — if keyword, filter by `POI.name.contains(keyword)` or `POI.category.contains(keyword)`
- **Do NOT use `POI.taste_tags.contains(keyword)`** — `taste_tags` is a JSON string (e.g., `["文艺","咖啡"]`), and SQLite `contains()` does substring matching which is unreliable for JSON. Instead, query a broader set and post-filter in Python: `json.loads(poi.taste_tags)` then check if keyword is in the list.
- If DB results < 3, also call `amap_service.search_pois(keywords=keyword, city=city)` for expansion
- Deduplicate by amap_id (DB results take priority)
- Return top 10 results as formatted Chinese text
- Each result: name, tier (★★★/★★/★), rating, highlight_note (if Tier A), coordinates
- Append "共 N 个结果，显示前 10 个" if total > 10
