<objective>
Wire dynamic Amap POI search into Stage 2 and pass user preferences through the pipeline.

Purpose: Currently Stage 2 only queries curated DB POIs — the pipeline can't discover new places beyond what's manually curated. Adding Amap search makes the POI pool dynamic and city-agnostic. User preferences (taste_tags_default, budget_default) are already stored in the User model but never reach the pipeline — they should influence scoring.

Output: Stage 2 with Amap expansion, user preference passthrough from API → coordinator → filter.
</objective>

```python
# --- Dynamic Amap expansion ---
amap_pois = []
if amap_service is not None:
    try:
        # Use intent.interests as search keywords for targeted expansion
        search_keywords = intent.interests[:5]  # limit to avoid excessive API calls
        if search_keywords:
            amap_results = await amap_service.batch_search_pois(
                city=intent.city,
                keyword_list=search_keywords,
                limit_per_keyword=10,
            )
            # Track existing amap_ids from curated DB for dedup
            existing_amap_ids = {p.amap_id for p in tier_a_rows + tier_bc_rows if p.amap_id}
            for poi_data in amap_results:
                if poi_data["amap_id"] not in existing_amap_ids:
                    amap_pois.append(poi_data)
                    existing_amap_ids.add(poi_data["amap_id"])
    except Exception as e:
        logger.warning(f"Amap expansion failed, continuing with DB-only: {e}")
```

```python
from backend.db.seed_pois import determine_tier

def _amap_to_candidate(poi_data: dict) -> POICandidate:

    rating = poi_data.get("rating")
    # Parse location "lng,lat" string
    loc = poi_data.get("location", "")

        name=poi_data.get("name", ""),
```
