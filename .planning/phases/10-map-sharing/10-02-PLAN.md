    ### 2. Create `MapView.vue`

    Per D-04, D-05, D-06, D-07, D-08, D-09: Amap JS map component.

    **Initialization:**
    - On mount, fetch `/api/config/amap-key` to get the JS API key
    - Use `AMapLoader.load({ key: response.key, version: '2.0' })` from `@amap/amap-jsapi-loader`
    - After load, create `new AMap.Map(containerRef, { zoom: 13, center: [...] })` — center calculated from POI coordinates

    **Props:**
    - `days: DayData[]` — full itinerary data
    - `activeDay: number | null` — currently selected day (null = show all)
    - `highlightPoiId: string | number | null` — externally triggered highlight (from timeline click)

    **Emits:**
    - `@marker-click(poiId: string | number)` — when a map marker is clicked (map→timeline sync)
    - `@day-select(dayNumber: number | null)` — when user interacts with the map (optional)

    **Markers (D-04):**
    - For each POI in the active day's data that has `latitude` and `longitude` defined, create an `AMap.Marker`
    - Use `content` property (custom HTML): render a div with the POI's tier symbol (★/○/◇) matching POINode tier config, and tier color background (`var(--color-tier-gold)`, `var(--color-tier-silver)`, `var(--color-tier-bronze)`)
    - Style: 28px circular marker, white text for symbol, colored background per tier, subtle box-shadow for depth
    - Offset the marker anchor so the marker point aligns with the POI location
    - Skip POIs without coordinates gracefully (no marker, no error)

    **Polylines (D-05):**
    - For each pair of consecutive POIs within a day (where both have coordinates), draw an `AMap.Polyline`
    - Use `strokeDasharray: [10, 5]` for dashed line effect. DO NOT use `strokeStyle: 'dashed'` (not a valid AMap property per CONTEXT)
    - Line color matches the day's route color: `var(--color-day-{N})` → convert CSS var to hex for Amap. Use the hex values directly: Day 1=#3B82F6, Day 2=#10B981, Day 3=#F59E0B
    - `strokeWeight: 3`, `strokeOpacity: 0.8`
    - Only show polylines for the active day (or all days if `activeDay` is null)

    **Auto-zoom (D-07):**
    - When `activeDay` changes, fit the map viewport to show all that day's markers with padding
    - Use `map.setFitView(dayMarkers)` where `dayMarkers` is the array of markers for the selected day
    - When `activeDay` is null (show all), fit all markers

    **Map→Timeline sync (D-09):**
    - When a marker is clicked, emit `@marker-click(poiId)` — the parent ItineraryView handles the timeline highlight
    - Also show an `AMap.InfoWindow` at the clicked marker's position with POI name, auto-close when another marker is clicked or the map is panned

    **Timeline→Map sync (D-08):**
    - When `highlightPoiId` prop changes (from external timeline click), find the corresponding marker and:
      - Pan the map to center on that marker: `map.setCenter([lng, lat])`
      - Open an InfoWindow at that marker if not already open
      - Visually emphasize the marker (e.g., bounce animation or size increase)

    **Cleanup:**
    - On unmount, call `map.destroy()` to clean up Amap resources
    - Remove all markers and polylines when days change (use `watch` on `days` and `activeDay`)
