    2. **Enrich itinerary GET endpoint in `itineraries.py`** — After parsing `parsed_itinerary` JSON in `get_itinerary()`, iterate through all POIs. Import Settings from config.py. Register this router in the main app (follow the pattern from stream.py or itineraries.py for router registration).

    5. **Update frontend types in `itinerary.ts`** — Add `latitude?: number` and `longitude?: number` fields to `POIVisitData` interface. These are optional because old itineraries and AI-generated POIs may lack coordinates.

    **Implementation details:**
    - For coordinate enrichment, use an async query inside the get_itinerary handler. Do NOT add a new database session — use the existing `db: AsyncSession = Depends(get_db)`.
    - Batch lookups: collect all unique `poi_id` values from all days, query `POI` objects by `POI.id.in_(poi_ids)`, build a dict mapping `poi_id → {latitude, longitude}`, then inject into each POI dict.
    - The meta endpoint should use the same `get_itinerary` pattern but only extract title/summary/city rather than the full itinerary.
    - Register the config router in the main app file (likely `src/backend/main.py` or similar) with prefix `/api`.
